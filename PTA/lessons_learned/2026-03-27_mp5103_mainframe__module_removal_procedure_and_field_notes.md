Physical module removal procedure for the MP5103 mainframe, plus real-world field observations from one week of use with an MSMU60-2 module. Not test automation — hardware handling and field deployment notes for FAE reference.

MP5103 mainframe, MSMU60-2 module (firmware v1.0.0)

## Gotchas / Problems Encountered
1. MODULE REMOVAL requires a two-hand simultaneous action that is not obvious: you must press INWARD on the spring bracket (right side of module) AND press DOWN on the release lever at the same time, then slide the module out. Doing one without the other will not release the module.

2. LOUD FAN NOISE: The MP5103 is significantly louder than a DPO7104AX and AWG70002B combined. Observed with firmware v1.0.0 with a single MSMU60-2 module drawing only 3.5-4A (powering a demo board at 5V, 0.76-0.79A load). Likely conservative fan control in early firmware — may improve in later releases.

3. FRONT PANEL SCREEN WENT BLANK after one use. The small configuration screen on the instrument stopped displaying anything. This did not affect instrument functionality since normal operation is through the GUI over LAN, but was surprising. Static IP had been set so LAN access was unaffected.

4. NOT TAA COMPLIANT — the MP5103/MSMU60-2 is not Trade Agreements Act compliant. This means US Air Force and many other DoD/federal customers cannot purchase it under current procurement rules.

5. SLOW ADOPTION EXPECTED in aerospace/defense accounts. Engineers see the value for automated test racks but integration requires another 50W PSU or SMU to go obsolete first, or a new development that needs a PSU/SMU slot. Not a quick sell.

## Solutions
Module removal procedure (from MP5103 User Manual, tek.com):
  1. Power OFF the mainframe
  2. Loosen the module retention screw
  3. Simultaneously: press INWARD on the spring bracket (right side, item 1) AND press DOWN on the release lever (item 2)
  4. Slide the module out and away from the mainframe

If front panel screen goes blank: instrument is still fully functional via LAN GUI, TSP, or SCPI. Ensure static IP is configured before deployment so LAN access is always available regardless of front panel display state.

## Measurement Tips
Observed power draw with MSMU60-2: 3.5-4A total from mainframe at 5V output, 0.76-0.79A load current into demo board. Single module only.

## Additional Notes
Trade show feedback: aerospace/defense engineers immediately understood the value proposition for automated test racks (compact modular PSU/SMU). The adoption barrier is integration timing — needs to displace an existing instrument or coincide with a new program start.
