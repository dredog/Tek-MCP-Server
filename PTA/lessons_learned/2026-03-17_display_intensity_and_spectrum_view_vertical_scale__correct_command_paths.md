# Lessons Learned: Display Intensity and Spectrum View Vertical Scale — Correct Command Paths

**Date:** 2026-03-17 09:37  
**Test Name:** Display Intensity and Spectrum View Vertical Scale — Correct Command Paths

## Summary
Documents two display-subsystem commands where the short-form path shown in the programmer manual index does not function on the instrument. The WAVEView1-rooted path is required for intensity, and SPECView1 is required for Spectrum View vertical scale. Discovered during MCP evaluation Q65 and Q79.

## Instruments Used
MSO 5/6 Series

## Key SCPI Commands
DISplay:WAVEView1:INTENSITy:WAVEform <NR2>     — waveform brightness/saturation (0-100)
DISplay:WAVEView1:INTENSITy:WAVEform?
DISplay:WAVEView1:INTENSITy:GRATicule <NR2>    — graticule brightness/saturation (0-100)
DISplay:WAVEView1:INTENSITy:GRATicule?
DISplay:SPECView1:CH1:VERTical:SCAle <NR3>     — Spectrum View vertical scale in dB/div
DISplay:SPECView1:CH1:VERTical:SCAle?

## Gotchas / Problems Encountered
1. DISplay:INTENSITy:WAVEform and DISplay:INTENSITy:GRAticule are listed in the programmer manual but do NOT work on the instrument. The commands appear to be accepted without error but have no effect.
2. DISplay:SPECView1:CH1:VERTical:SCAle is the correct command for Spectrum View vertical scale — NOT CH1:SCAle (which is time-domain only) and NOT DISplay:WAVEView1:CH1:VERTical:SCAle (which is V/div for time domain).

## Solutions
Always use the WAVEView1-rooted path for intensity commands:
  DISplay:WAVEView1:INTENSITy:WAVEform 75
  DISplay:WAVEView1:INTENSITy:GRATicule 75
For Spectrum View vertical scale, use the SPECView path:
  DISplay:SPECView1:CH1:VERTical:SCAle 10.0  (10 dB/div)

## Measurement Tips
The WAVEView index x is nearly always 1. The SPECView index x is also nearly always 1. Only use other values if multiple waveform or spectrum views have been explicitly created.

## Additional Notes
These corrections are now documented in Tektronix_Automation_Guidelines.md sections 18 and 19 (v1.9). The correct SPECView command was verified against the MSO 4/5/6 JSON command database: DISplay:SPECView<x>:CH<x>:VERTical:SCAle.
