# Lessons Learned: Channel Enable/Disable — CH<x>:STATE Undocumented Shorthand and SELect Failure Case

**Date:** 2026-03-27 23:35  
**Test Name:** Channel Enable/Disable — CH<x>:STATE Undocumented Shorthand and SELect Failure Case

## Summary
Documents an undocumented but reliable SCPI shorthand for enabling/disabling channels on MSO 4/5/6 Series, and a known failure case for the commonly used SELect:CH<x> command when used with certain probes.

## Instruments Used
MSO 4/5/6 Series oscilloscopes; confirmed with TLP058 optical probe

## Key SCPI Commands
CH1:STATE ON      — enable channel 1 (undocumented shorthand, most reliable)
CH1:STATE OFF     — disable channel 1
CH1:STATE?        — query channel state
SELect:CH1 ON     — alternative, works on most configurations
DISplay:GLObal:CH1:STATE ON  — fully documented long form

## Gotchas / Problems Encountered
1. CH<x>:STATE is NOT in the MSO 4/5/6 Programmer Manual but works reliably on the instrument including in cases where SELect:CH<x> fails.
2. SELect:CH<x> ON confirmed to NOT work with TLP058 optical probe. CH<x>:STATE ON works correctly in the same situation.
3. DISplay:GLObal:CH<x>:STATE is the only fully documented form but is verbose.

## Solutions
Use CH<x>:STATE {ON|OFF} as the default channel enable/disable command in all automation scripts. It is the most reliable form across all tested configurations including probe types that cause SELect:CH<x> to fail. Fall back to DISplay:GLObal:CH<x>:STATE if needed for documentation compliance.

## Measurement Tips
If a channel is not appearing on screen after what should be a successful enable command, try switching from SELect:CH<x> to CH<x>:STATE — especially when using specialty probes (optical, differential, high-voltage).

## Additional Notes
Discovered during field use with TLP058 optical probe. CH<x>:STATE is not in the JSON command database (not in the programmer manual) but is confirmed working. Documented in Tektronix_Automation_Guidelines.md section 10c as of v1.10.
