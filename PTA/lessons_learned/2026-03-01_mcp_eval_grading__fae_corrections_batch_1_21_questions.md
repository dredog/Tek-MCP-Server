## Key SCPI Commands

HORizontal:MODe:MANual:CONFIGure {HORIZontalscale|RECORDLength} — CRITICAL missing command. In MANual mode, use RECORDLength to fix sample rate while scale changes adjust record length.
MEASUrement:MEAS1:VALue? — simpler single-value query (alternative to RESults:CURRentacq:MEAN?).
CH<x>:TERmination — valid values are 50 (50 ohm) or 1E6 (1 Mohm). Do not just say NR3 format, give actual valid values.
CH<x>:PROBEFunc:EXTAtten and EXTDBatten — SAME on MSO 2 Series AND MSO 4/5/6. Do NOT say MSO 2 uses a different command (PROBe:GAIN). The JSON may be wrong on this.


## Gotchas / Problems Encountered

1. HORizontal AUTO mode: The record length target (~1 Mpt/ch) is NOT the maximum record length — it is an arbitrary hardcoded value. Max record lengths vary: MSO2=10Mpts, MSO4=31.25Mpts (opt 62.5M), MSO5/6=62.5Mpts (opt to 1Gpts). Using the word 'maximum' is INCORRECT.
2. CH<n>:POSition is NOT deprecated on MSO 4/5/6. It is simply less precise than OFFset for vertical positioning. Never say it is deprecated.
3. MSO 2 probe attenuation: EXTAtten and EXTDBatten are the same on MSO 2 as MSO 4/5/6. Do NOT say MSO 2 uses CH<n>:PROBe:GAIN for external attenuation.
4. SignalVu reference: When someone asks about SignalVu SCPI commands, reference the SignalVu Programmer Manual. Do not comment on which internal docs contain which commands.
5. Remote UI access: When someone asks about controlling a scope from a PC, also mention remote UI options — not just SCPI. MSO2 and Windows-based MSO5/6 and DPO7 have a VNC server (accessible via Remote Desktop, TightVNC, etc.). Linux MSO4/5/6/7 have eScope — just navigate to the scope IP address in a web browser. No extra software needed for eScope.
6. Finding VISA address on instrument: Always mention Utilities -> I/O on the scope's front panel/UI to find the IP address and VISA resource string. Do not only mention PC-side tools.
7. TekVISA versions: When recommending TekVISA, mention that v5.11.1 does NOT work with SignalVu-PC. A previous version should be used if SignalVu-PC integration is needed. Link to the older version if available.

  scope.write("HORizontal:MODe:MANual:CONFIGure RECORDLength")

For VISA address discovery on instrument: go to Utilities -> I/O menu on scope UI.
For eScope (Linux scopes): open browser, type scope IP address — no install needed.
For SignalVu SCPI: direct user to SignalVu Programmer Manual at https://www.tek.com/en/sitewide-content/manuals/s/i/g/signalvu-vector-analysis-software-programmer-manual


## Measurement Tips

Always mention MEASUrement:MEAS1:VALue? as a simple alternative to RESults:CURRentacq:MEAN? for single measurement reads.
For termination, always state the two allowed values explicitly: 50 (50 ohm) or 1E6 (1 Mohm). Do not just reference NR3 format generically.
