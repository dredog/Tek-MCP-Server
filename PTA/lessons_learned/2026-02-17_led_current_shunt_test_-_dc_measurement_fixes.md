# Lessons Learned: LED Current Shunt Test - DC Measurement Fixes

**Date:** 2026-02-17 13:09  
**Test Name:** LED Current Shunt Test - DC Measurement Fixes

## Summary
Fixed three issues with the LED Current Shunt test in Tek PTA: (1) replaced PROBEFunc:EXTAtten with SCALERATio for voltage-to-current conversion, (2) replaced single-sequence acquisition with run/wait/stop for DC steady-state measurements, (3) added instrument disconnect UI buttons.

## Instruments Used
MSO24 oscilloscope, Keithley 2450 SMU

## Key SCPI Commands
CH<x>:SCALERATio <NR2> — converts voltage to current (ratio = 1/R_shunt). For 10Ω: CH3:SCALERATio 0.1. For 500mΩ: CH2:SCALERATio 2. Measurement readouts return actual amps. ACQuire:STOPAfter RUNSTOP + ACQuire:STATE RUN + sleep(0.5) + ACQuire:STATE STOP — correct acquisition for DC steady-state. ACQuire:NUMACq? — verify at least one acquisition completed. CH<x>:PROBEFunc:EXTAtten 1 — MSO2 only, for BNC/SMA (MSO2 doesn't auto-detect). CH<x>:PROBEFunc:EXTAtten 10 — MSO2 only, for passive probes.

## Gotchas / Problems Encountered
1. PROBEFunc:EXTAtten is for probe attenuation compensation, NOT for shunt current scaling. Use SCALERATio for V→A conversion. 2. Single-sequence (ACQuire:STOPAfter SEQuence) hangs on DC signals because there are no real trigger events. AUTO trigger may fire but single-seq gate can miss it. 3. MSO2 does NOT auto-detect probe attenuation — must set EXTAtten manually. MSO4/5/6 auto-detects TekVPI/TPA probes. 4. Disabled "✓ Active" buttons prevented users from disconnecting instruments without restarting the app.

## Solutions
1. Use CH<x>:SCALERATio (ratio = 1/R_shunt) for shunt current. Scope handles all conversion — measurement readouts are actual amps. 2. Use run/wait/stop pattern for DC: RUNSTOP → RUN → sleep(0.5) → verify NUMACq → STOP → read measurement. Reserve single-seq for triggered events (edges, delay, serial data). 3. Detect scope model from *IDN? and branch: MSO2 needs EXTAtten, MSO4/5/6 auto-detects. 4. Replaced disabled Active buttons with Disconnect buttons that call InstrumentManager.disconnect_<type>() and refresh the UI. SMU disconnect turns off output first for safety.

## Measurement Tips
When to use which acquisition mode: SINGLE SEQUENCE — triggered events (pulse edges, rise/fall, delay, serial eye diagrams). RUN/WAIT/STOP — DC steady-state (shunt current, PSU output, mean/RMS of stable signals). The run/wait/stop pattern: (1) STOPAfter RUNSTOP, (2) STATE RUN, (3) sleep 0.5s, (4) verify NUMACq > 0, (5) STATE STOP, (6) read measurement.

## Additional Notes
SCALERATio vs EXTAtten cheat sheet: SCALERATio → shunt current (V→A). EXTAtten 1 → MSO2 BNC cable. EXTAtten 10 → MSO2 passive probe. Neither → MSO4/5/6 with TekVPI probe (auto). Updated TEK_PTA_PLUGIN_GUIDE.md Section 5 with acquisition strategy guide, SCALERATio usage, and MSO2 probe differences.
