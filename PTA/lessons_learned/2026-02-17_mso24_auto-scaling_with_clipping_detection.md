# Lessons Learned: MSO24 Auto-Scaling with Clipping Detection

**Date:** 2026-02-17 14:19  
**Test Name:** MSO24 Auto-Scaling with Clipping Detection

## Summary
Developed a coarse-to-fine auto-scaling routine for MSO2 series scopes that uses Autoset as a starting point, checks for clipping, then optimizes vertical and horizontal scales programmatically.

## Instruments Used
MSO24 oscilloscope

## Key SCPI Commands
CH<x>:CLIPPing? — native clipping detection query (returns 0 if not clipping). CH<x>:SCAle — accepts arbitrary values (not limited to 1-2-5), scope snaps to nearest valid step. CH<x>:OFFSet — set to signal midpoint to center waveform. HORizontal:MODe:SCAle — also accepts exact values, scope snaps. MEASUrement:ADDMEAS PK2PK/FREQUENCY/HIGH/LOW — temp characterization measurements. MEASUrement:LIST? returns "MEAS1,MEAS2,..." format (not bare numbers) even with HEADer OFF.

## Gotchas / Problems Encountered
1. Autoset can clip signals — never trust HIGH/LOW/PK2PK measurements without checking CH<x>:CLIPPing? first. 2. MEASUrement:LIST? returns MEAS-prefixed tokens even with HEADer OFF — must strip "MEAS" prefix before parsing integers. 3. Vertical scale is NOT limited to 1-2-5 steps — 300 mV/div, 600 mV/div etc. are valid. Always read back CH<x>:SCAle? to see what scope actually set. 4. Target 80% fill (pk2pk / 8 divs). Over 90% is too tight (can't see onset of clipping), under 50% wastes screen real estate.

## Solutions
1. Use Autoset as starting point (good for horizontal), then check CH<x>:CLIPPing? on each channel. For clipping channels, widen to 5 V/div with 0V offset and re-acquire before characterizing. 2. Strip MEAS prefix: token.strip().upper().replace("MEAS", "") before int(). 3. Send exact computed scale value (pk2pk / (10 * 0.80)) and read back actual setting. 4. Offset = (HIGH + LOW) / 2 centers the signal on screen.

## Measurement Tips
For 80% fill: v_scale = pk2pk / (NUM_DIVS * 0.80). For 3 cycles on screen: h_scale = 3 / frequency / NUM_DIVS. Send exact values and let scope firmware snap to nearest valid step, then read back to confirm.
