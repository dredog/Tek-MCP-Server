Complete live-verified TDR setup sequence for MSO68B using external AWG70002B fast edge. TDRPREset EXECute is the correct command to initialize all scope settings for TDR. AUTOSet is not usable.

## Gotchas / Problems Encountered
1. AUTOSet EXECute returns 40 µs/div with external AWG TDR signal — completely wrong, do not use. 2. TDRPREset EXECute is asynchronous — must sleep(8) before any subsequent writes or reads or settings will be overwritten by the preset. 3. TDRPREset always resets CH1 bandwidth to full (10 GHz) — BW limit must be applied AFTER the 8-second wait. 4. HORizontal:MODe MANual required before increasing RECOrdlength beyond preset value on MSO68B. 5. MEASUrement:MEAS1:TDR:* sub-commands (EQUAlize, STEPdetect, SIGnaltype etc.) time out — do not query them. 6. Built-in TDR returns 9.91E+37 (Invalid input) with external AWG — expected, scope needs its own fast edge for internal calibration.

## Solutions
Correct sequence: (1) TYPe TDR + SOUrce1 + STATE ON, (2) TDRPREset EXECute, (3) sleep(8), (4) apply BW limit, (5) HORizontal:MODe MANual + RECOrdlength 20000, (6) push Math formula. Manual Math formula Z=Z0*(V-V_b)/(2*V_m-V_b-V) is the reliable measurement path with external AWG.

## Measurement Tips
TDRPREset sets: H scale 4.5597 ns/div, H position 10%, record 2280 pts (20 ps/pt), ACQ AVE/20, full BW, trig -62 mV FALL on CH1. These values match exactly what the scope UI TDR preset button does. Increasing record length to 20000 gives 2.3 ps/pt for smoother impedance derivative used in feature detection.
